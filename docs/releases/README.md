# MeoUI release history

This directory keeps versioned release notes and the changelog that must stay
with the MeoUI source. It replaces root-level release-note clutter.

- `CHANGELOG.md`: chronological release changes.
- `RELEASE_NOTES_*.md`: version-specific release assets and validation notes.

New release documentation belongs here only when it is a maintained record of
the versioned deliverable. Planning, one-off publication text, or agent work
logs belong in the MeoUI Obsidian project record instead.
