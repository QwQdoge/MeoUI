# Navigation System Inventory

- `MeoNavigationSuite`: Five-class adaptive container with compact overflow drawer
- `MeoNavigationBar`: Compact bottom bar
- `MeoNavigationRail`: Medium compact rail or 240 dp expanded docked pane, with grouped and scrollable destinations
- `MeoNavigationDrawer`: Large or extra-large permanent side drawer, held at a stable 280 dp unless an app opts into wider composition
- `MeoTopAppBar` / `MeoSearchAppBar`: Top bars
- `MeoBreadcrumbs`: Breadcrumb hierarchy
- `MeoTabs`: Segmented tabs
